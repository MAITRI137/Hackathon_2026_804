# UX / Productivity Review Checklist

For each role and major workflow, verify:

## Information architecture
- Is the primary next action obvious within 3–5 seconds?
- Are blockers more prominent than decorative KPIs?
- Are advanced options progressively disclosed?
- Does role navigation omit irrelevant modules while backend authorization remains enforced?
- Is there a fast path and a full-detail path?

## Interaction cost
- Can the task be completed inside its target interaction budget?
- Is repeated work batchable?
- Are known values prefilled safely?
- Can related data be inspected without losing context?
- Are there unnecessary Apply/Continue screens?
- Is a confirmation protecting a real risk, or just adding friction?

## Forms
- Required/common fields first.
- Advanced fields secondary.
- Specific errors.
- Input preserved after errors.
- Clear one-primary-action hierarchy.
- Duplicate submission prevented.
- High-impact change previews consequence.

## Tables
- Search works.
- Useful sort works.
- Multi-select appears only when batch actions exist.
- Batch bar lists relevant actions.
- Row actions are visible/consistent.
- Supplementary detail is expandable/sidecar.
- Money aligns and uses tabular numerals.
- No dead overflow items.

## Charts
- Live data only.
- Hover/focus shows exact values.
- Chart does not require click to understand.
- Zero-data state is sensible.
- Filters update chart correctly.
- Underlying authorized records can be inspected where useful.

## Motion
- Every animation has a purpose.
- No hover gradient buttons.
- No repetitive bounce.
- Frequent actions remain fast.
- Reduced Motion works.
- Motion is never the only feedback.

## Accessibility
- Focus visible.
- Focus not obscured.
- Keyboard path works.
- Labels/errors associated.
- Target size/spacing reasonable.
- Color not sole status signal.

## Joy
- Success feels acknowledged but not theatrical.
- New/changed values can highlight briefly.
- Graph hover feels precise.
- Drag/drop or reorder feels direct if used.
- Empty states make the next action obvious.
- No screen feels sterile or overloaded.
